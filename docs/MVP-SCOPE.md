# MVP Scope

## Included now

- Itinerary scenario model
- Pickup/dropoff logic
- Route-leg index
- Destination activity windows
- Operational events
- Meal and accommodation logic
- Cost components
- Recommendation rules
- Map/PDF/page payload skeleton
- Validation skeleton

## Excluded for now

- Full dashboard
- MCP server
- Vector database
- Live DB sync
- PII import
- Auto-write to old repositories
- Payment/invoice integration
- Crew scheduling automation

## Why this scope

The fastest useful result is not a dashboard. The fastest useful result is a reliable generated dataset that can answer route, cost, and itinerary feasibility questions.
